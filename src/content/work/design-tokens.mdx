Documentation is often the first task to lose time when a software project gets complex. The
goal of this project was to turn source code into useful project documents without asking
developers to explain the same system by hand every time.

I built an AI-assisted platform with Node.js APIs and Claude 3 Sonnet, including code analysis,
review summaries, and document generation in formats suited to different users. The tool was
designed to reduce developer workload while making unfamiliar projects easier to understand.

The result was a practical developer tool rather than a generic chatbot: its value came from
connecting AI output to the structure and maintenance needs of a real web project.
