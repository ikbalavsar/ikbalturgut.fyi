Several teams had drifted into slightly different versions of the same buttons, spacing, and
color. Rather than mandate a rewrite, I built a token pipeline and a migration path teams
could adopt one component at a time.

The hard part was social, not technical: making the shared system the path of least
resistance so consistency happened by default.
